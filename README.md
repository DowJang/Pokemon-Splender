# 포켓몬 스플렌더 (개인용 디지털판)

보드게임 "포켓몬 스플렌더"를 휴대폰 브라우저에서 AI 상대와 1:1로 즐기기 위한
개인용 웹 구현입니다. **비상업·비배포** 목적이며, 원본 게임과 포켓몬 관련 권리는
각 권리자에게 있습니다.

---

## 실행

`app/` 폴더가 통째로 정적 웹앱입니다. 빌드 과정이 없습니다.

로컬에서 바로 확인:

```bash
npx --yes http-server app -p 8123 -c-1
```

브라우저에서 `http://localhost:8123` 로 접속합니다.
(`file://` 로 직접 열면 ES 모듈 로딩이 막히므로 반드시 HTTP 로 띄워야 합니다.)

## 개인 git 서버에 올려 휴대폰으로 접속하기

1. 저장소를 서버에 올립니다.

   ```bash
   git init && git add . && git commit -m "포켓몬 스플렌더 웹앱"
   git remote add origin <내 git 서버 주소>
   git push -u origin main
   ```

2. 서버에서 `app/` 디렉터리를 정적으로 서빙합니다 (nginx 예시).

   ```nginx
   location /splendor/ {
       alias /srv/pokemon-splendor/app/;
       try_files $uri $uri/ /splendor/index.html;
   }
   ```

3. 휴대폰에서 해당 주소로 접속 → 브라우저 메뉴의 **홈 화면에 추가**.
   앱처럼 전체화면으로 실행되고, 한 번 열어 두면 오프라인에서도 동작합니다.

> **HTTPS 주의** — 서비스 워커(오프라인 실행·홈 화면 추가)는 HTTPS 또는
> `localhost` 에서만 동작합니다. HTTP 로 서빙하면 게임은 정상 동작하지만
> 오프라인 캐시는 꺼집니다.

> **업데이트가 안 보일 때** — 코드는 네트워크 우선으로 받으므로 새로고침하면
> 반영됩니다. 그래도 옛 화면이 보이면 `app/sw.js` 의 `CACHE` 값을
> `poke-splendor-v4` 처럼 올리고 다시 배포하세요.

## 게임 규칙 요약

원본 설명서(`Box/설명서_01~03.jpg`)를 그대로 옮겼습니다.

- **목표** — 먼저 **18점**에 도달하면 그 라운드를 끝까지 진행한 뒤 종료.
  동점이면 ① 진화를 많이 시킨 사람 ② 앞에 놓인 카드가 많은 사람 순으로 승리.
- **인원** — 사람 1명과 AI 상대 1명의 **1:1 전용**.
- **토큰** — 몬스터볼·슈퍼볼·퀵볼·힐볼·하이퍼볼 + 마스터볼(만능) 5개.
  일반 볼은 색마다 4개.
- **차례에 하나만** —
  1. 서로 다른 색 토큰 3개
  2. 같은 색 토큰 2개 (그 색이 4개 이상 남았을 때)
  3. 카드 1장 예약 + 마스터볼 1개 (손 최대 3장, 희귀·전설은 예약 불가)
  4. 포켓몬 잡기 (비용 지불 후 자기 앞에 배치)
- **진화** — 행동이 아니며 차례를 마칠 때 한 마리만. 조건은 **카드 보너스**로만
  판정하고 아무것도 소모하지 않습니다. 다음 단계 카드가 시장이나 손에 있어야 하고,
  교체된 이전 카드는 트레이너 타일 밑으로 들어가 점수·보너스를 잃습니다.
  희귀·전설 카드는 보너스를 2개로 계산합니다.
- **토큰 보유 한도** 10개 (초과분은 차례 종료 시 자동 반납).

## 상대 난이도

| 이름 | 코드 | 특징 |
|---|---|---|
| 초보자 | `novice` | 눈앞의 점수와 토큰만 봅니다. 보너스의 장기 가치와 진화 계획을 못 보고, 가끔 엉뚱한 수를 둡니다. |
| 수련자 | `adept` | 보너스 가치·진화 가능성까지 계산하고 상대 한 턴을 내다봅니다. |
| 장프로 | `pro` | 실수하지 않으며, 후보 수마다 자기 턴을 여러 번 굴려 **18점까지 몇 턴**인지 직접 재고 최단 경로를 고릅니다. |
| 김마귀 | `kimmawi` | 장프로의 최단 경로 계산에 더해 **상대의 최선 응수**를 읽고, 예약·선점으로 상대의 계획을 끊습니다. |
| 나일롱머스크 | `nylongmusk` | 더 넓은 후보를 대상으로 **16수 장기 맞대결 롤아웃**을 수행해 김마귀의 후속 계획까지 읽습니다. |
| 화성신 | `marsgod` | 시장의 유력 후보를 더 넓게 비교하며 **24수 맞대결 롤아웃**으로 나일롱머스크의 장기 계획을 읽습니다. |
| 우주신 | `spacegod` | 가장 넓은 후보를 대상으로 **40수 맞대결 롤아웃**을 수행하는 진짜 최고 난이도입니다. |

자체 대전 결과 (자리 순서를 교대해 편향 제거, 각 90판):

```
수련자 vs 초보자     80% : 20%
장프로 vs 초보자     83% : 17%
장프로 vs 수련자     68% : 32%
```

새 최고 난이도 자체 대전 결과 (자리 순서를 교대해 편향 제거, 각 60판):

```
김마귀 vs 장프로             63% : 37%
나일롱머스크 vs 김마귀       60% : 40%
```

새 난이도 한 수의 데스크톱 평균 계산 시간은 김마귀 5ms 이내,
나일롱머스크 10ms 이내입니다.

추가 최고 난이도 자체 대전 결과 (자리 순서를 교대해 편향 제거, 각 40판):

```
화성신 vs 나일롱머스크       55% : 45%
우주신 vs 화성신             60% : 40%
```

화성신은 한 수당 평균 약 17ms, 우주신은 약 25ms로 계산합니다.

## 구조

```
app/
  index.html          화면 골격
  style.css           모바일 세로 레이아웃
  manifest.webmanifest / sw.js   PWA (홈 화면 추가 · 오프라인)
  js/
    data.js           카드 90장 · 진화 계통 · 토큰 규칙 (원본 사진에서 추출)
    engine.js         규칙 엔진 (순수 함수, 상태 복제로 AI 탐색에 재사용)
    ai.js             난이도 7종
    app.js            UI 컨트롤러
  assets/sprites/     포켓몬 이미지 55종 (PokeAPI 공식 아트웍)
tools/
  fetch_sprites.py    스프라이트 내려받기 (1회성)
  simulate.mjs        규칙 검증 + AI 승률 벤치마크
  tune.mjs            장프로 파라미터 튜닝
  tune_hard.mjs       최고 난이도 서열 + 응답 시간 검증
Box/                  원본 설명서·진화표·카드목록 사진
```

게임 화면의 상단에는 상대, 하단에는 내 카드 현황이 고정됩니다. 두 패널 모두
획득 카드와 보라색 마스터볼로 찜한 카드를 구분해서 보여 줍니다.

### 카드 구성 (원본과 동일)

| 덱 | 장수 | 내용 |
|---|---|---|
| 1단계 | 35 | 기본 포켓몬 15종 (색깔 계열당 7장) |
| 2단계 | 30 | 중간 진화 15종 × 2장 |
| 3단계 | 15 | 최종 진화 15종 × 1장 |
| 희귀 | 5 | 라프라스·메타몽·프테라·잠만보·이브이 (보너스 2, 0점) |
| 전설·환상 | 5 | 썬더·뮤·프리져·파이어·뮤츠 (보너스 2, 2점) |

## 검증

```bash
node tools/simulate.mjs 30   # 데이터 무결성 + 규칙 불변식 + 난이도 승률
node tools/tune.mjs 30       # 장프로 파라미터 비교
```

`simulate.mjs` 는 매 턴 토큰 총량 보존, 음수 토큰, 손패 3장 초과, 토큰 10개 초과,
카드 중복을 검사합니다.
